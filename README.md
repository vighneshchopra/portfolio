## Technical Stack & Architecture

- **Frontend:** Semantic HTML5, Tailwind CSS, JetBrains Mono & Plus Jakarta Sans typography
- **Canvas Engine:** Adaptive 60Hz Pro / 30Hz Eco quantum particle simulation with battery-conserving visibility listeners
- **Interactive Triage:** Simulated 4-phase hospital incident escalation and root-cause workflow
- **Security & Privacy:**
  - Zero formula/CSV injection vulnerability with dual-layer sanitization
  - Decoupled telemetry pipeline with anonymous session clumping
  - Deceptive anti-spam bot defense without tracking vulnerabilities
  - Privacy-first GA4 and Microsoft Clarity integration with strict PII masking

---

## Security & Architecture

| Layer | Implementation Details |
| :--- | :--- |
| **Formula Injection Defense** | Dual-layer client & backend sanitization prepending `'` to execution prefixes (`=`, `+`, `-`, `@`, `\t`, `\r`) |
| **Anti-Spam Verification** | Deceptive off-screen input trap with silent drop logic (zero bot keywords) |
| **Data Separation** | Telemetry and recruitment contact inquiries are strictly isolated to prevent quota exhaustion |
| **Privacy Compliance** | Strictly zero-PII analytics logging; user inputs are masked in telemetry session replays |
